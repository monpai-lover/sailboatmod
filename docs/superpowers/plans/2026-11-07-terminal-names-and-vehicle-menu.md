# 车站、机场名称与登记载具快捷菜单

> **For agentic workers:** Use subagent-driven-development. Root alone runs Gradle and operates live worlds; preserve existing navigation and logistics changes.

**Goal:** 完成剩余运输回归，并实现城镇默认站名、可覆盖命名和登记载具 R 键目的地菜单，完成后推送。

**Architecture:** 车站和机场仅保存自定义名称；空值在服务端动态解析所属城镇名称。R 键复用载具管理界面和既有发车入口，由服务端确定玩家所在的真实载具并检查登记、权限和任务状态。

**Tech Stack:** Java 21、NeoForge 1.21.1、Create、Aeronautics/Sable、JUnit。

## 名称

- [ ] 驿站、铁路货运站、机场在未自定义名称时显示当前 town 名称；不更改原港口的命名规则。
- [ ] UI 保存名称作为覆盖；清空恢复跟随。旧存档已有非空名称保持为自定义名称。
- [ ] 更名后界面、终端网络和目的地列表一致；铁路原生站台身份仍使用稳定 ID。
- [ ] 回归：town 改名、覆盖后 town 再改名、清空恢复、存档读回、无 town、无权限。

## R 键

- [ ] 复用已有 R 键配置，保留原帆船和马车菜单。
- [ ] 玩家在真实已登记的物理载具中时，请求服务端打开已有控制器目的地界面。
- [ ] 服务端确认同一载具、可管理权限和唯一控制器；不接受客户端任意控制器坐标。
- [ ] 复用正常目的地选择、可达性、燃油和货单占用校验。
- [ ] 回归：同船、他人载具、无登记、多个控制器、离开载具、仍有货运任务。

已归档的实机通过项是陆车两轮、列车两轮，以及铁路满仓等待后的跨版本重启恢复。海运仅验证装货、地形等待、普通停车与货款保全；原单交付、重复海运和本轮航空回归尚未通过。第 74 版完整构建记录为 3897 项、0 失败、5 项跳过；不能据此宣称新增功能或实机矩阵已完成。

## 名称缓存边界

城镇更名会立即刷新已加载的默认命名终端及界面；尚未加载的远端终端保留已发布名称，待其区块加载时更新。因此，R 菜单中的远端目的地标签可能短暂显示旧名称。目的地标签仅从同维度、同类型、航线末点附近唯一已登记端点读取；有多个候选时保留航线原名称，不猜测端点，也不凭名称相等推断用户是否设置过自定义名称。

# 遊戲內窗口尺寸與排版調整

日期：2026-10-14。交付版本：1.3.13-fix_5，Minecraft 1.21.1 / NeoForge 21.1.259。
驗證狀態：已完成。

本輪檢查全部遊戲內窗口及其分頁，調整尺寸造成的擠壓、裁切、零寬文字及捲動問題。尺寸依實際 GUI 空間限制；不變更玩家的 Minecraft 界面比例。

## 改動範圍

- 市場最大窗口由 640×400 增至 920×600。實測 GUI 2／3／4 商品每行分別為 4／4／3 張；GUI 4 六張商品顯示為三列兩行。窄畫面點擊商品開啟詳情浮層，返回、外部點擊及 ESC 可關閉；寬畫面保留詳情側欄。數量輸入沿用同一個元件，縮放、關閉及重新開啟詳情後保留草稿。
- 市場出售、配送、求購與指數在窄畫面上下排列；購買確認框限制尺寸並可捲動。名稱、價格、Bid／Stock、財務說明與輸入框各自分配寬度；下拉選單文字不覆蓋箭頭，通知不超過窗口。
- 修正 LDLib2 普通標籤預設不量測寬度造成的零寬文字：共用文字元件量測自然寬度並限制繪製範圍，有固定空間的名稱和數值使用明確欄位，長文字可懸停閱讀。段落依可用寬度換行並保留所需高度，周圍列表縮短並捲動。
- 國家／城鎮窗口擴寬；身份欄限制在標題區。國庫與經濟指標卡片至少 90 像素並換行，稅率／狀態條獨占下一行，城鎮概覽、圖表及預覽區在窄畫面上下排列。成員、外交、旗幟與權限的長名稱限制在自身欄位。
- 銀行貸款恢復指標名稱；國庫余额大字獨占一行，倉儲詳情和長物品名稱不越過側欄。
- 帆船、馬車、居民和家族窗口擴寬並加入有界捲動；操作可換行，自動導航、姓名、狀態與座位文字有明確尺寸。保留既有按鈕、權限及封包。
- 碼頭／驛站終端偏好寬度由 236 增至 320。窄畫面的路線／調度列表和操作區上下排列，進階操作移到列表下方；保留全部玩家格子並同步原生點擊座標。
- 巢狀列表只有發生實際位移才攔截滾輪，空列表、內容恰好等高或到達邊界時交給外層。內層捲軸上的滾輪不會同時移動外層。內層捲動區可完整放進外層視口。
- 建築目錄與詳情在窄畫面上下排列，目錄高度依實際外層空間調整；預覽和說明上下排列，提示限制在確認／取消之前。國家交易雙方可上下排列及捲動，狀態與操作分行。
- 道路工具列依可用高度分欄，繪製和點擊共用布局；材料卡、目的地、道路方案、建築和居民等選擇器處理長中文名稱。道路目的地提示不再被壓縮，消除浮點高度反覆重排。

捲軸沿用 fix_4 的 120 ms 淡入、900 ms 保留、250 ms 淡出；懸停或拖曳時保持顯示。貨款交貨後支付、舊單退款先追回款項、私有退貨及庫存識別規則保留；網路協定仍為 12。

## 修復前證據

- `dimensions-auxiliary-red.json` 與原十張截圖保存文字零高度、過度擠壓及繪製越界。舊可達性檢查仍可能 passed，不能把它描述成所有可達性檢查失敗。
- `dimensions-dock-nested-red.json` 記錄六個失敗：內層列表寬高超過外層，以及空列表吞掉外層滾輪；最終容器回歸全通過。
- `dimensions-structure-nested-red.json` 記錄兩個主題的內層目錄高於外層視口；最終依實際高度調整後通過。
- `dimensions-road-layout-red.json` 記錄 Road Targets 提示的 173／180 個穩定區事件，高度在 8.254437／8.2544365、候選高度在 9／8.999999 間反覆；修復後均為零。BUILDING 在 RED 時即為零。
- 額外截圖保存銀行缺少貸款指標名稱及建築目錄高度問題。舊市場 GUI 4 的六張卡片只有一列，本版已驗證三列兩行。

舊整合與捲軸基線分別見 `UI_REPAIR_2026-10-13.md` 和 `UI_SCROLLBARS_2026-10-14.md`；本輪結果以 fix_5 報告為準。

## 安裝與重跑

`sailboatmod-1.21.1-neoforge-fix_5.zip` 的 `mods/` 包含主模組、GeckoLib 4.9.3 和 LDLib2 2.2.42。客戶端及伺服器同步更新並移除同模組舊 JAR。`server-only-mods/` 是可選網頁市場附加模組；Tellus／TellusMinimap 不包含在本安裝包。

證據 ZIP 保存本輪 JSON、269 張有效引用截圖、12 張修復前截圖、日誌及隔離啟動器。啟動器不包含在正式 JAR。

原生入口為 `all-client.init.gradle` 和 `container-client.init.gradle`；後者使用 `-PuiSmokeScale=2/3/4`。`-PuiRoadOnly=true` 重跑聚焦道路和巢狀滾輪案例。驗證器為 `tools/verify_ingame_ui_smoke.py`。隔離測試客戶端位於 `build/ui-repair-smoke/game`。

# 游戏内地图路线图层：FIX 11

Minecraft 1.21.1、Java 21、NeoForge 21.1.259+；主模组版本 1.3.13-fix_11。此更新接续 fix_10 的 Tellus 预测／真实底图与分段长途规划，给道路规划器、Town、Nation 三个地图加入共用路线显示。

## 使用方式

1. 打开道路规划器，或 Town／Nation 的领地地图，在地图工具列点击地图图标，打开“地图路线”。
2. 分别切换“道路”“陆路”“航线”：金色为已建道路，绿色为陆运路线，青色为码头航线。开关会立即筛选已收到的路线。
3. 开启“查看路线”，返回地图后用左键点选线路。选中线路会高亮，详情显示名称、类型、起终点及约略长度；设置窗口也能查看完整文字。
4. 中键拖动、滚轮缩放仍可移动地图。关闭“查看路线”后，左键恢复原有道路编辑或领地选择用途。

路线按当前维度的公开登记目录显示，显示不授予编辑、调度或领地操作权限。码头使用已保存的路线快照；驿站新增独立持久化目录，区块卸载后仍可显示。旧驿站在正常加载／使用时补录；尚未登记的私人物品路线、载具私有任务和运单不在地图目录中。

驿站正常刷新时，目标已知但区块尚未加载的自动路线仅保留在地图目录；实际发车只使用本次有效路线。目标已加载而连接失效时清除旧自动路线；真正拆除目标时清理相关自动路线缓存，手动登记路线独立保留。

## 大范围地图与显示边界

路线与底图共用坐标变换；视野边界按线段裁切，包含两端都在地图外、但中间穿过地图的线段。远景会简化显示，不会修改实际导航航点。原始距离可在预算内读取时保留；否则按压缩显示路径估算，界面统一标为约数。

单次回复最多 128 条路线、4096 个点、256 段且小于 128 KiB。密集视野在已捕获的可见分类间轮流分配，给其他分类保留最低几何额度。源目录捕获也有总预算，超过时显示“仅显示部分路线”，应放大或移动视野查看局部；不能把有限显示当成完整世界线路清单。

地图请求只读取已登记的目录，不读取私有任务／库存，不强制加载远方区块，不触发全网寻路。工作线程仅处理冻结数据，旧请求、切换维度和退出世界后的回复会被丢弃。

## 安装

- 客户端与服务端都更新主模组，并安装 GeckoLib 4.9.3、LDLib2 2.2.42。
- 网络协议升级为 **14**；两端必须同步更新。可选市场网页附属只安装在服务端。
- Tellus 0.8.3／TellusMinimap 是可选配套；路线图层也能独立使用。
- fix_10 的物理载具依赖与验收边界继续适用，见 [fix_10 说明](TELLUS_TRANSPORT_FIX_10.md)。本次地图更新没有改变 Sable 上游重启问题，也不代表带动力运输和完整物流往返已验收。

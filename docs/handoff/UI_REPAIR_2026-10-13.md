# LDLib2 UI 整合與修復驗證

驗證日期：2026-10-13 至 2026-10-14。發布檔名：1.3.13-fix_3 / NeoForge 1.21.1。

完整回傳包 SHA-256：`cbe9159dfa946fd525c86f409900ef1e31fdc8fcfb4617541f6c866fc13bfe61`。已核對原交接檔案雜湊，整合 119 個來源／建置變更；被替換的基線另存於 `build/ui-repair-integration-backup-20261013`。

## 修復結果

- 國家／城鎮畫面先建立標題元件，再建立會讀取它們的內容，修復首次開啟崩潰。
- 所有共用畫面、保留的上層畫面、市場與道路規劃器在每次掛載時重新訂閱主題，關閉時解除訂閱；重複初始化不增加監聽器。
- 橫向操作按鈕按可用寬度分配，狀態文字在範圍內顯示；銀行金額與貸款輸入框不再被擠至零寬。
- 固定視窗尺寸在 LDLib2 置中之前一併限制，修復小畫面向左偏移。銀行保留物品欄位置，貸款及物品明細可捲動。
- 市場標題、目錄、詳情、上架及財務頁面縮排／捲動；倉庫 90 格在 GUI 4 的 320×240 畫面內完整顯示。
- 碼頭／驛站等容器在最終排版後同步可見格子的原生點擊座標，與繪製位置一致。
- Ledger 輸入背景、格子、按鈕配色使用正確的樣式優先級；共用控制項範圍同時涵蓋道路規劃器與市場浮動下拉選單。
- 清除市場篩選時同步搜尋、稀有度、價格選項，保留排序；清除後再次篩選仍正常。
- 銀行儲存標題的字高改為固定單行，消除 `9.000001 ↔ 8.999999` 的持續排版迴圈。
- 庫存識別涵蓋物品與完整元件，忽略數量且排序巢狀 NBT 鍵。庫存重排／數量改變時保留同一變體；伺服器在扣除物品之前拒絕過期或缺失識別。文字指紋保留精確 UTF-16 單位，避免不同元件字串被替換字元合併。
- 既有同步伺服器／網頁上架介面保留；權限檢查先於個人庫存存取。封包格式更新後協定升至 **12**，兩端須同步更新。

既有货款保管、交貨後付款、舊單先追回卖家款項才退款、私有退貨運單及權限規則未回退。

## 安裝

`sailboatmod-1.21.1-neoforge-fix_3.zip` 的 `mods/` 含主模組、GeckoLib 4.9.3、LDLib2 2.2.42，客戶端及伺服器均安裝。`server-only-mods/` 是可選網頁市場附加模組，只放伺服器。先移除同模組舊版 JAR，避免重複載入。Tellus／TellusMinimap 仍為可選模組。

完整截圖、原生 JSON、測試摘要與可重跑的隔離測試啟動器另在 `sailboatmod-ingame-ui-fix_3-validation.zip`。測試啟動器只供開發驗證，不加入正式模組。

# 遊戲內捲軸修復與驗證

驗證日期：2026-10-14。正式版本：1.3.13-fix_4，Minecraft 1.21.1 / NeoForge 21.1.259。

捲動時捲軸在 120 ms 內淡入，停止後保留 900 ms，再於 250 ms 內淡出。滑鼠停在捲軸位置或拖曳期間持續顯示。淡出只改變視覺透明度，保留可喚醒的滑鼠區域及固定捲軸空間；沒有溢出的區域不顯示捲軸。

## 修復範圍

- 共用捲動元件涵蓋市場、銀行、碼頭、驛站、國家／城鎮、居民列表和選擇器；市場內部下拉選單使用同一套捲軸效果。
- 限制捲動元件及其父層的高度，修復 GUI 4 中商品列表高 466、詳情高 547，但畫面只有 240 而沒有捲軸的情況。
- 成員與外交詳情加入獨立捲動區；國庫、領地／權限及長表單可捲動到末端。窄畫面領地資訊與地圖上下排列，旗幟資訊換行，顏色輸入框保留可用寬度。
- 碼頭與驛站的分頁依可用高度收縮，操作側欄、運單詳情、調度摘要和進階內容可捲動；保留玩家物品欄並同步原生格子座標。
- 調整兩種主題的捲軸軌道與滑塊對比。窄列表的標題限制在自身欄位內。
- 固定垂直捲軸空間，消除捲軸出現／消失引發文字寬度改變和持續排版循環。尺寸改變時重新通知庫計算最終內容範圍，避免內容縮短後殘留錯誤滑塊。
- 中斷淡入／淡出、移除及重新掛載元件時清除舊動畫候選，避免殘留半透明狀態。

完整 LDLib2 整合、庫存變體識別與既有市場財務修復見 `UI_REPAIR_2026-10-13.md`。交貨後才支付賣家、舊單退款先追回款項及私有退貨貨物規則保持原有行為。網路協定仍為 12。

## 安裝與重跑

`sailboatmod-1.21.1-neoforge-fix_4.zip` 的 `mods/` 包含主模組、GeckoLib 4.9.3 和 LDLib2 2.2.42；兩端安裝並移除同模組舊 JAR。`server-only-mods/` 是可選網頁市場附加模組。Tellus／TellusMinimap 為可選模組。

`sailboatmod-ingame-ui-fix_4-validation.zip` 包含目前報告引用的 197 張截圖、原生 JSON、失敗／通過證據及隔離測試啟動器。啟動器只供開發驗證，不包含在正式 JAR。

原生驗證入口是 `build/ui-repair-smoke/all-client.init.gradle` 與 `container-client.init.gradle`；容器以 `-PuiSmokeScale=2/3/4` 指定比例。`tools/verify_ingame_ui_smoke.py` 檢查產生的結果。完整回傳整合來源及相依庫固定版本見 `LDLIB2_INTEGRATION.md`。

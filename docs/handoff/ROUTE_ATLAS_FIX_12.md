# 独立交通地图：FIX 12

本次按用户修正，将路线查看功能迁到独立物品与专用 LDLib2 界面。Minecraft 1.21.1、Java21、NeoForge21.1.259+，外置前置 GeckoLib4.9.3、LDLib2 2.2.42。

## 获取与操作

- 物品「交通地图」，ID `sailboatmod:route_atlas`，创造模式 SailboatMod 栏可取得。
- 生存模式：四张纸＋一个指南针，无序合成一张；不消耗使用次数，不绑定某条私有路线。
- 手持右键打开独立大地图。三个按钮分别控制金色道路、绿色陆运、青色航线；左键点选线路查看名称、类型、起终点和约略距离。
- 中键拖动、滚轮缩放；指南针按钮回到玩家位置，保留当前缩放。调整界面尺寸保留视角，切换世界或维度重新以玩家为中心；关闭再打开使用新的请求会话。
- 此界面只查看线路，不提交道路建造、领地选择、调度或强制渲染操作。

## 与其他界面的关系

Town、Nation、道路规划器已移除 fix_11 新增的路线图层、按钮与点击接管。它们原有的底图、领地管理和道路规划功能继续使用；规划器自身已有的施工／道路视觉也保留。网页地图未接入这套新增图层，原有网页功能保持。

独立交通地图继续使用已登记道路、码头和驿站目录，以及 actual／Tellus 共用底图。未知地形预测按视野逐步出现，实际数据覆盖预测。请求不会为填充地图而强制生成远处区块；不读取玩家私有任务、物品路线或运单库存。

fix_11 的有界传输、断开线段裁切、稳定路线身份和驿站卸载快照保留逻辑继续使用。单次最多128条路线、4096点、256段且小于128KiB；超出会提示仅显示部分。地图显示不授予编辑或调度权限。

## 安装与验证边界

主模组与 GeckoLib／LDLib2 放客户端和服务端，替换旧版，避免重复；市场网页附属只放服务端。网络协议为 **15**，两端同步更新。Tellus／TellusMinimap 和物理模组是可选依赖，使用及 Sable2.0.6 上游重启限制沿用 [fix_10](TELLUS_TRANSPORT_FIX_10.md)。

游戏验证使用 `Route-overlay-validation` 测试副本及通过真实目录登记的合成线路，原存档不参与修改。Town／Nation 概览夹具仅用于界面负向检查；不能替代完整多人流程。测试源仅在忽略的 build 目录，正式包不包含这些类。

完整回归 **1936 项通过，0失败／错误／跳过**，正式 `releaseMod -PfixIndex=12` 构建及网页前端检查通过。交通地图 GUI2／3／4 的实际地图范围均在屏幕内；实际物品 use 调用、原生鼠标点选与分类按钮、平移／缩放／回中以及英文控件均已检查。首次窗口超出屏幕的问题通过将尺寸计算提前到界面定位之前修复。RoadPlanner／Town／Nation 的实机反向截图不含新增路线覆盖层及入口，相关源文件也已对照接入前基线。

原世界84个文件与无关网页交接工具的校验保持不变。真实鼠标点击验证的是线路与分类控件；物品开图通过游戏正常的 `useItem` 路径调用，面向可交互方块时仍遵循 Minecraft 先处理方块交互的规则。
